# Everything you need to use and build MamaBear

MamaBear is an e-commerce experience for pregnancy, postpartum recovery, nursing, and childcare needs. This documentation explains how to use the customer and administration experiences and how contributors can run and extend the frontend.

## Choose a guide

- [User Guide](/docs/user-guide/authentication) — create an account, discover products, place orders, manage your account, and operate the admin dashboard.
- [Developer Guide](/docs/developer-guide/getting-started) — install the project, understand its architecture, work with authentication and APIs, and run quality checks.

## What you can do

Customers can browse and search the catalog, get product suggestions through chat, manage a cart and promotional codes, check out with saved delivery details, and review orders and invoices.

Authorized administrators can monitor store performance and manage products, categories, promotions, orders, customers, reports, store settings, and administrator accounts.
